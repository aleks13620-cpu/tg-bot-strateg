# Стратег-Ассистент — Описание функций для пользователя

> Бот помогает предпринимателям двигаться к стратегическим целям через систему спринтов, ежедневного планирования и аналитики фокуса.

---

## НАВИГАЦИЯ

| Кнопка / Команда | Функция |
|---|---|
| `/start` | Первый запуск / приветствие |
| `/menu` или кнопка `🏠 Меню` | Главное меню |
| Кнопка `🎯 Спринты` | Управление спринтами |
| Кнопка `📋 Добавить задачи` | Планирование дня |
| Кнопка `🌙 Закрыть день` | Вечернее закрытие дня |
| `/today` | Мой план на сегодня |
| `/progress` | Аналитика и статистика |
| `/finance` | Финансовые цели |
| `/done` | Быстро отметить задачу выполненной |

---

## 1. ПЕРВЫЙ ЗАПУСК

### Регистрация и знакомство с ботом
- **Как вызвать:** команда `/start`
- **Что делает:** Регистрирует пользователя, объясняет концепцию (Спринт → Инициативы → Задачи → SFI) и предлагает создать первый спринт. Возвращающимся пользователям показывает главное меню.
- **Связанные функции:** Создание спринта, Обзор возможностей

### Обзор возможностей
- **Как вызвать:** кнопка `💡 Что ещё умеет бот` (в приветственном сообщении)
- **Что делает:** Показывает краткое описание всех функций бота — планирование, закрытие дня, SFI, спринты, еженедельный отчёт.
- **Связанные функции:** Создание спринта

---

## 2. СПРИНТЫ

### Просмотр активных спринтов
- **Как вызвать:** кнопка `🎯 Спринты` на постоянной клавиатуре
- **Что делает:** Показывает все активные спринты с целью, датами и направлениями. Для каждого доступны кнопки редактирования и завершения.
- **Связанные функции:** Редактирование спринта, Завершение спринта, Создание спринта

### Создание нового спринта
- **Как вызвать:** кнопка `🚀 Создать спринт` (из главного меню или приветствия)
- **Что делает:** Запускает 3-шаговый мастер создания спринта: формулировка цели → добавление 1–5 направлений → выбор длительности (7, 14 или 21 день). В конце показывает карточку подтверждения.
- **Связанные функции:** Редактирование спринта, Планирование дня

### Завершение спринта
- **Как вызвать:** кнопка `✅ Завершить` в карточке спринта (раздел `🎯 Спринты`)
- **Что делает:** Закрывает активный спринт и показывает итоговую карточку: цель, статистика выполнения, SFI, стрик, прогресс по финансовой цели.
- **Связанные функции:** Аналитика по спринту

### Редактирование цели спринта
- **Как вызвать:** `🎯 Спринты` → `✏️ Редактировать` → `📝 Изменить цель`
- **Что делает:** Позволяет переформулировать главную цель текущего спринта — бот попросит написать новый текст.
- **Связанные функции:** Просмотр спринтов

### Редактирование направлений (инициатив)
- **Как вызвать:** `🎯 Спринты` → `✏️ Редактировать` → `📋 Редактировать направления`
- **Что делает:** Показывает список всех направлений спринта. Каждое можно переименовать или удалить. Можно добавить новое направление (максимум 5).
- **Связанные функции:** Просмотр спринтов

### Установка финансовой цели спринта
- **Как вызвать:** `🎯 Спринты` → `✏️ Редактировать` → `💰 Изменить финцель`
- **Что делает:** Устанавливает денежную цель для спринта. Сначала выбирается валюта (₽ / $ / €), затем вводится сумма. Финцель отображается в прогрессе и еженедельном отчёте. Можно убрать цель кнопкой `🗑 Убрать финцель`.
- **Связанные функции:** Финансовый прогресс

### Установка SFI-цели спринта
- **Как вызвать:** `🎯 Спринты` → `✏️ Редактировать` → `🏆 SFI-цель (%)`
- **Что делает:** Задаёт целевой процент стратегического фокуса для спринта (число от 1 до 100). Цель отображается в еженедельном отчёте как ориентир.
- **Связанные функции:** Аналитика, Еженедельный отчёт

## 3. ПЛАНИРОВАНИЕ ДНЯ

### Добавление задач на день
- **Как вызвать:** кнопка `📋 Добавить задачи` на постоянной клавиатуре
- **Что делает:** Открывает выбор даты (ближайшие 14 дней или ввод вручную), затем принимает список задач текстом (каждая с новой строки или через запятую). После ввода запускается квалификация каждой задачи.
- **Связанные функции:** Квалификация задачи, Просмотр плана на сегодня

### Квалификация задачи (привязка к стратегии)
- **Как вызвать:** запускается автоматически после добавления задач
- **Что делает:** Для каждой задачи предлагает выбрать: к какому направлению (инициативе) спринта она относится, или отметить её как `🔥 Вне стратегии`. Задачи, привязанные к направлениям, учитываются в SFI как стратегические.
- **Связанные функции:** SFI, Выбор задачи дня

### Выбор задачи дня (звёздочка)
- **Как вызвать:** задаётся в процессе квалификации после выбора инициативы
- **Что делает:** Позволяет отметить одну задачу как главную на день (`⭐ Задача дня`). Она выделяется в плане и упоминается в утреннем напоминании.
- **Связанные функции:** Утреннее напоминание, Просмотр плана на сегодня

### Добавление задачи из пересланного сообщения
- **Как вызвать:** переслать любое сообщение с текстом в чат с ботом
- **Что делает:** Предлагает добавить текст пересланного сообщения как задачу — спрашивает дату и запускает квалификацию.
- **Связанные функции:** Квалификация задачи

### Просмотр плана на сегодня
- **Как вызвать:** команда `/today`
- **Что делает:** Показывает все задачи на сегодня, сгруппированные по направлениям (стратегические) и `🔥 Вне стратегии`. Для каждой задачи — кнопки `✅ выполнено` / `⏭ пропустить`. В шапке — прогресс-бар спринта и текущий стрик.
- **Связанные функции:** Закрытие дня, Спринт, Стрик

### Быстрое выполнение первой задачи
- **Как вызвать:** команда `/done`
- **Что делает:** Автоматически отмечает первую незавершённую задачу сегодняшнего дня как выполненную и показывает обновлённый план.
- **Связанные функции:** Просмотр плана на сегодня

### Редактирование задач
- **Как вызвать:** кнопка `✏️ Редактировать задачи` (появляется при просмотре плана через `/plan`)
- **Что делает:** Показывает все задачи дня с кнопками: `🗑 Удалить` (удаляет задачу) и `🔄 Сменить инициативу` (переквалифицировать задачу в другое направление или вне стратегии).
- **Связанные функции:** Квалификация задачи

## 4. ЗАКРЫТИЕ ДНЯ

### Закрытие дня
- **Как вызвать:** кнопка `🌙 Закрыть день` на постоянной клавиатуре, команда `/close`
- **Что делает:** Показывает все незакрытые задачи дня. Для каждой нажмите `✅ Сделано` или `⏭ Пропущено`. После отметки всех задач — кнопка `📊 Показать итоги дня`.
- **Связанные функции:** Итоги дня, Перенос задач, Стрик, Коучинг

### Итоги дня
- **Как вызвать:** кнопка `📊 Показать итоги дня` (в конце закрытия дня)
- **Что делает:** Показывает статистику: сколько задач выполнено, SFI (% стратегических задач), стрик. При достижениях — мотивационные сообщения (3/7/14/30 дней стрика, SFI 80%+).
- **Связанные функции:** SFI, Стрик, Перенос задач

### Перенос незавершённых задач на завтра
- **Как вызвать:** появляется автоматически после итогов дня, если есть пропущенные задачи
- **Что делает:** Предлагает перенести все пропущенные задачи на завтра одной кнопкой `✅ Перенести все`. После переноса показывает план на завтра. Можно отказаться кнопкой `⏭ Не переносить`.
- **Связанные функции:** Закрытие дня, Просмотр плана

### Устаревшие задачи (задачи прошлых дней)
- **Как вызвать:** появляются в утреннем напоминании автоматически, если pending-задачи старше 2 дней
- **Что делает:** Показывает список "зависших" задач. Для каждой можно: `✅ выполнено`, `⏭ пропустить` или `📅 Сегодня` (перенести на сегодня).
- **Связанные функции:** Планирование дня, Утреннее напоминание

## 5. СТРИК

### Стрик — дней подряд
- **Как вызвать:** отображается автоматически в `/today`, утреннем напоминании и итогах дня
- **Что делает:** Считает количество дней подряд, в которые пользователь закрывал день с выполненными задачами. При достижении 3, 7, 14 и 30 дней — поздравление. При разрыве утром придёт уведомление о сбросе стрика.
- **Связанные функции:** Закрытие дня, Итоги дня, Аналитика

---

## 6. АНАЛИТИКА И ПРОГРЕСС

### Аналитика (главный раздел)
- **Как вызвать:** команда `/progress`
- **Что делает:** Показывает статистику сегодняшнего дня (выполнено/пропущено/SFI) и список всех спринтов для детального просмотра.
- **Связанные функции:** Статистика по спринту, Итоги недели

### Статистика по спринту
- **Как вызвать:** `/progress` → выбрать нужный спринт из списка
- **Что делает:** Показывает итоги выбранного спринта: общее количество задач, процент выполнения, SFI, количество стратегических vs оперативных задач. Доступна кнопка `📊 По всем спринтам`.
- **Связанные функции:** Сравнение всех спринтов, Итоги недели

### Сравнение всех спринтов + график SFI
- **Как вызвать:** `/progress` → `📊 По всем спринтам`
- **Что делает:** Показывает сводную таблицу по всем спринтам (выполнено задач, SFI). Если спринтов 2 и больше — дополнительно отправляет **линейный график SFI** по всем спринтам в хронологическом порядке.
- **Связанные функции:** Статистика по спринту

### Итоги недели
- **Как вызвать:** `/progress` → `📅 Итоги недели`
- **Что делает:** Показывает недельную статистику: задачи, SFI, сравнение с предыдущей неделей (рост/падение). Можно листать назад по неделям кнопкой `◀ Пред. неделя`.
- **Связанные функции:** Статистика по спринту

## 7. ФИНАНСОВЫЕ ЦЕЛИ

### Финансовый прогресс
- **Как вызвать:** команда `/finance`
- **Что делает:** Показывает все спринты с финансовой целью: прогресс-бар выполнения (накопленная сумма / цель), историю внесённых сумм по неделям. При наличии 2+ спринтов с финцелями — дополнительно отправляет **столбчатый график** достижения финцелей.
- **Связанные функции:** Установка финансовой цели, Внесение прогресса

### Внесение финансового прогресса за неделю
- **Как вызвать:** `/finance` → кнопка `💰 Внести за эту неделю` (или из еженедельного отчёта)
- **Что делает:** Предлагает ввести сумму заработанного за текущую неделю. После ввода сохраняет данные и показывает обновлённый прогресс-бар к финансовой цели спринта.
- **Связанные функции:** Финансовый прогресс, Еженедельный отчёт

## 8. КОУЧИНГ

### Коучинговый вопрос после закрытия дня
- **Как вызвать:** появляется автоматически после итогов дня (в зависимости от результатов)
- **Что делает:** Бот задаёт вопрос для рефлексии, подобранный по ситуации:
  - SFI < 50% → вопрос про стратегический фокус
  - Много задач вне стратегии (>3) → вопрос про делегирование
  - Все задачи пропущены → вопрос про причины
  - SFI ≥ 70% → похвала и мотивация
  - Пятница → мотивационное сообщение
- **Связанные функции:** Закрытие дня, SFI

### Ответ на коучинговый вопрос
- **Как вызвать:** кнопка `💬 Ответить` под коучинговым вопросом
- **Что делает:** Принимает текстовый ответ пользователя и сохраняет его. Можно пропустить кнопкой `⏭ Пропустить`.
- **Связанные функции:** Коучинговый вопрос

## 9. ЗАГРУЗКА ФАЙЛА

### Импорт задач из текстового файла
- **Как вызвать:** отправить `.txt` файл в чат с ботом
- **Что делает:** Парсит файл и показывает его содержимое в виде нумерованного списка. Предлагает кнопки для быстрого перехода к созданию спринта или планированию дня.
- **Связанные функции:** Создание спринта, Добавление задач

## 10. АВТОМАТИЧЕСКИЕ НАПОМИНАНИЯ

> Бот сам присылает сообщения по расписанию — ответы от пользователя не требуются, но доступны кнопки для быстрых действий.

### Утреннее напоминание
- **Когда:** ежедневно в 8:00 МСК
- **Что делает:** Присылает сводку: цель спринта с прогресс-баром, стрик, задача дня (`⭐`), количество задач на сегодня, ближайшие запланированные дни. Кнопка `📋 Мой план` для открытия плана. Если есть устаревшие задачи (>2 дней) — показывает их с кнопками действий.

### Напоминание в полдень
- **Когда:** будни в 13:00 МСК (только если есть задачи и ни одна не выполнена)
- **Что делает:** Напоминает, что день ещё не закрыт и есть незавершённые задачи.

### Вечернее напоминание
- **Когда:** ежедневно в 18:00 МСК (только если день не закрыт)
- **Что делает:** Напоминает закрыть день, показывает количество незавершённых задач и план на завтра. Кнопка `📊 Закрыть день`.

### Еженедельный отчёт
- **Когда:** каждую субботу в 10:00 МСК
- **Что делает:** Присылает итоги недели: задачи, SFI, сравнение с прошлой неделей, прогресс к финансовой цели (если задана) и SFI-цель. Кнопка для внесения финансового прогресса.
- **Связанные функции:** Итоги недели, Финансовый прогресс

### Напоминание о возвращении
- **Когда:** понедельник в 9:00 МСК (только если пользователь не заходил 3+ дней)
- **Что делает:** Присылает мотивирующее сообщение с напоминанием об активном спринте и призывом вернуться к работе.

## КОНЦЕПЦИЯ SFI (Strategic Focus Index)

**SFI** — процент выполненных задач, которые были привязаны к направлениям (инициативам) спринта.

- `SFI = стратегические выполненные / все выполненные × 100%`
- Цель: **70%+** — большинство времени уходит на стратегию, а не на "тушение пожаров"
- Задачи `🔥 Вне стратегии` снижают SFI
- SFI отображается в итогах дня, статистике спринта и еженедельном отчёте
