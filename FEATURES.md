## Планирование задач

- Добавление задач текстом — построчно или через запятую
- Датпикер на 14 дней вперёд + ручной ввод ДД.ММ
- Пересланные сообщения → автоматически предлагает создать задачу
- Квалификация каждой задачи: стратегическая (по инициативе) или оперативная 🔥
- Отметка «задача дня» ⭐
- Плановое время: 15 / 30 / 60 / 120 мин или вручную
- Редактирование задач: удалить, переквалифицировать
- Загрузка списка задач из .txt файла

## Выполнение задач (Today)

- Список задач сгруппирован: по инициативам → стратегические → оперативные
- Статус задачи: ⬜ pending / ✅ done / ⏭ skipped
- Кнопки: выполнено, пропустить, перенести на завтра, отменить (undo)
- SFI и стрик в подвале сообщения
- Устаревшие задачи: пометить / перенести / пропустить

## Закрытие дня

- Разбор каждой задачи: выполнена / пропущена
- Фактическое время (preset + ручной ввод)
- Причина пропуска (7 вариантов)
- Перенос невыполненных задач на завтра
- Расчёт SFI и обновление стрика
- Мотивационные сообщения при 3 / 7 / 14 / 30 днях стрика
- Коучинговый вопрос по итогам дня (5 сценариев)
- Еженедельный разбор просроченных задач

## Спринты

- Создание: цель → тип (спринт 7–21 дн / 30-дневная цель) → инициативы (1–5) → длительность
- Управление: завершить, архивировать, продлить на 7 / 14 / 30 дней
- Редактирование: цель, инициативы, финансовая цель, SFI-challenge
- Финансовая цель: сумма + символ (₽ / $ / #)
- SFI-challenge: целевой % стратегического фокуса
- Карточка завершения со статистикой

## Аналитика

- Статистика дня: выполнено, SFI, разбивка по инициативам
- Статистика спринта: прогресс-бар, выполнено / стратегических
- Статистика по неделям с навигацией пред / след
- График SFI по всем спринтам

## Финансы

- Прогресс-бар факт vs. план с символом валюты
- История последних 5 недель
- Ввод еженедельного результата

## Метрики (для 30-дневных целей)

- До 3 метрик на цель
- Типы: количество (шт), рубли (₽), проценты (%), да/нет
- Ввод целевого и текущего значений

## Квартальный обзор

- 9 вопросов в 4 блоках: достижения → анализ → личное → следующий квартал
- Возобновление с прерванного места
- Итоговая формулировка 90-дневного фокуса
- Быстрое создание спринта из фокуса
- История завершённых обзоров

## Настройки

- Время утреннего напоминания (default 8:00)
- Время вечернего напоминания (default 18:00)
- Часовой пояс: Москва, Киев, Минск, Алматы, Новосибирск, Владивосток
- Вкл / выкл все напоминания

| Понедельник | Реактивация | Если не активен >3 дней |

## Ключевые метрики

- **SFI** (Strategic Focus Index) = стратегические выполненные / всего выполненных × 100%
  - 🟢 ≥70% · 🟡 50–69% · 🔴 <50%
- **Стрик** — дни подряд с закрытым планом (done > 0)
