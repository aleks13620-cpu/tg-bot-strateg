# Стратег-Ассистент — Telegram-бот для предпринимателей

> Роль AI в текущей версии: узкий пилот в вечернем коучинговом вопросе.  
> Планирование, учёт задач, статусы, SFI и навигация работают по явным правилам (без автопилота).

## Для кого этот бот?

Для предпринимателей и самозанятых, которые хотят двигаться к стратегическим целям, но постоянно тонут в текучке. Бот помогает не просто вести список задач, а видеть — работаете ли вы над тем, что действительно важно, или только «тушите пожары».

---

## Как это работает — 3 уровня

**1. СПРИНТ** — ваша главная цель на 1–3 недели (или 30 дней)
Вы формулируете одну фокусирующую цель. Например: *«Расширить ближний круг»* или *«Запустить новый продукт»*.

**2. ИНИЦИАТИВЫ** — 3–5 направлений для достижения цели
Это не задачи, а области работы. Например: *«Деловые встречи»*, *«Бизнес-клубы»*, *«Контакт с Иваном»*.

**3. ЗАДАЧИ** — конкретные действия на каждый день
Привязанные к инициативам. Например: *«Найти клубы в городе → обзвонить → записаться»*.

Каждый вечер бот считает **SFI (Strategic Focus Index)** — процент задач дня, которые двигали вас к цели спринта, а не просто «решали проблемы». Это ваш главный показатель фокуса.

---

## Что умеет бот

### Планирование
- Каждое утро бот присылает напоминание и предлагает запланировать день
- При добавлении задачи — можно указать, сколько времени планируете потратить (15 мин / 1 час / своё значение)
- Задачи привязываются к инициативам спринта или отмечаются как «вне стратегии»
- Можно пометить одну задачу как **ключевую на день** ⭐ — она всегда стоит первой
- Импорт задач из текстового файла .txt (построчно)

### Закрытие дня
- Вечером бот показывает список задач дня — отмечаете каждую: ✅ выполнена / ⏭ пропущена / 📅 перенести
- При выполнении — фиксируете фактическое время (15 мин / 2 часа / своё)
- При пропуске — выбираете причину (не хватило времени / расфокус / слишком большая задача и др.)
- После закрытия — бот показывает итоги: SFI, стрик, сколько времени потрачено на стратегию и на текучку
- Незакрытые задачи можно перенести на завтра или на конкретную дату

### Типы спринтов
**Обычный спринт** (7 / 14 / 21 день) — с инициативами и ежедневными задачами.

**30-дневная цель** — без деления на недели, с метриками прогресса:
- Добавляете метрики (в штуках, рублях, процентах или «да/нет»)
- Обновляете значения по ходу месяца
- Видите прогресс-бары по каждой метрике

### Финансовые цели
- К любому спринту можно привязать финансовую цель (например: *«500 000 ₽»*)
- Еженедельно вносите фактический результат
- Бот строит график динамики по неделям и показывает прогресс-бар к цели

### Аналитика
- `/progress` — полная статистика: SFI по спринту, выполнено задач, стрики
- **График SFI** по всем спринтам — видно как менялся ваш фокус
- **Еженедельный отчёт** (по субботам) — таблица выполнения по инициативам с предупреждениями ⚠️ о нулевом прогрессе
- Причины пропуска задач за неделю — если одна причина повторяется часто, бот даёт коучинговую подсказку
- Стрики — считает дни подряд с закрытием дня, поздравляет с рекордами

### Разбор несделанного
Каждую неделю бот предлагает разобрать незакрытые задачи прошлой недели:
- 📅 Перенести на конкретную дату
- ✂️ Упростить (переформулировать задачу)
- ❌ Отменить

### Квартальный обзор
Раз в квартал бот запускает структурированный разбор по 4 блокам:
1. Результаты — что достигнуто, что нет
2. Анализ — почему так, что мешало
3. Личное — энергия, баланс
4. Следующий квартал — фокус, цели

Обзор можно прервать и продолжить позже — ответы сохраняются. По завершении — предлагает сразу создать 30-дневную цель.

### Напоминания (настраиваемые)
- 🌅 Утреннее — планирование дня
- ☀️ Дневное — если к обеду задачи ещё не начаты
- 🌆 Вечернее — закрытие дня
- 📊 Еженедельный отчёт по субботам
- 🔄 Напоминание о возвращении если не заходили 3+ дня

Через `/settings` настраиваете время утра и вечера, часовой пояс (Москва / Киев / Минск / Алматы / Новосибирск / Владивосток), включаете или выключаете напоминания.

## Команды

| Команда | Что делает |
|---------|------------|
| `/start` | Регистрация, создание первого спринта |
| `/plan` | Добавить задачи на сегодня |
| `/today` | Посмотреть план на сегодня |
| `/close` | Закрыть день (отметить задачи) |
| `/progress` | Аналитика и статистика |
| `/finance` | Финансовые цели и прогресс |
| `/metrics` | Метрики 30-дневной цели |
| `/review` | Начать / продолжить квартальный обзор |
| `/reviews` | История завершённых обзоров |
| `/settings` | Настройки напоминаний и часового пояса |
| `/menu` | Главное меню |

## Главная идея

Большинство инструментов продуктивности помогают делать больше. Этот бот помогает делать **правильное** — то, что реально двигает к вашей стратегической цели. SFI каждый день честно показывает: вы строили бизнес или разгребали входящие.

## Где используется AI сейчас

- Только в одном месте: генерация формулировки коучингового вопроса после закрытия дня.
- Если AI недоступен, бот автоматически использует обычный шаблонный вопрос.
- AI не меняет задачи, статусы, сроки или приоритеты без пользователя.
